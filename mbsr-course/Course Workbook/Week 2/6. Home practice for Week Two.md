## Pleasant Events Journal

As well as the body scan, this week I’d like you to use the table below to make a log of some pleasant events for the coming 7 days.

It’s best if these events are fairly small – not big, life-changing things but instead “little noticings”. Someone smiles at you in the street or says something nice about your work, you catch a glimpse of something in nature that makes you stop for a minute, or your dog does something silly that makes you laugh.

See if you can log at least one of these each day for the next 7 days.

|                                                                       | Mon | Tues | Wed | Thurs | Fri | Sat | Sun |
| --------------------------------------------------------------------- | --- | ---- | --- | ----- | --- | --- | --- |
| What was your experience / pleasant event?                            |     |      |     |       |     |     |     |
| How did the body feel during the experience?                          |     |      |     |       |     |     |     |
| Describe the thoughts or images that accompanied the event?           |     |      |     |       |     |     |     |
| Describe your mood, feelings and emotions that accompanied the event? |     |      |     |       |     |     |     |
| What thoughts and feelings are in your mind now as you recall the event?           |     |      |     |       |     |     |     |
|                                                                       |     |      |     |       |     |     |     |


### Notes:

- Log pleasant events as soon as possible after they happen so they’re fresh in your mind
- Notice what happens
- Use the questions above to focus on the detail of the experience – but don’t be constrained by these – if you want to write more, do so!


## 9 Dots

The 9 dots challenge asks you to link all nine dots below using four straight lines or fewer, without lifting your pen and without tracing the same line more than once.

Before you get going, take note of your feelings and experience:

1. What does it feel like to be challenged like this?
2. Have you done this challenge before? Does this affect how you feel?
3. How do you feel during the task?
4. How about afterwards?
