# Formal practice log

Print this page or copy it into a notebook, and fill it in as you go. The log is not a test and nobody will collect it; it simply helps you see your own practice honestly, and it is worth glancing back over previous weeks as the course goes on.

## How to use it

- One line per formal practice: body scan, sitting practice, movement, walking, loving kindness, and so on.
- Note minutes where you can, but a session you finished while distracted still counts. Only sessions you skipped leave the line blank.
- The final column is the useful one: one honest sentence about what the session was actually like.
